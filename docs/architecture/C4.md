# Architecture (C4 Model)

This document describes the .NET MCP server using the [C4 model](https://c4model.com/):
Context, Container, and Component views, followed by the end-to-end request flow for
the two MCP tools the server exposes.

## Level 1 — System Context

Who/what talks to the system, and why.

```mermaid
C4Context
    title System Context — MCP Web Performance Intelligence

    Person(operator, "Developer / Analyst", "Wants a technical performance audit of a website")
    System(mcpClient, "MCP Client", "Claude Desktop, an IDE, or any LLM agent that speaks MCP and orchestrates tool calls")
    System(mcpServer, "MCP Web Performance Intelligence", ".NET 10 MCP server exposing analyze_website and suggest_improvements tools")
    System_Ext(pagespeed, "Google PageSpeed Insights API", "Runs Lighthouse audits and returns performance metrics")

    Rel(operator, mcpClient, "Asks to audit a URL")
    Rel(mcpClient, mcpServer, "Calls MCP tools over stdio (JSON-RPC)")
    Rel(mcpServer, pagespeed, "Requests Lighthouse metrics for a URL", "HTTPS")
    Rel(mcpServer, mcpClient, "Returns JSON metrics / recommendations")
    Rel(mcpClient, operator, "Synthesizes a technical report")
```

**Key point:** the server is model-agnostic. The original proof of concept hard-wired
Gemini as the orchestrator; as a standard MCP server, any MCP-speaking client or model
can discover and call these same two tools.

## Level 2 — Container

```mermaid
C4Container
    title Container View — MCP Web Performance Intelligence

    Person(operator, "Developer / Analyst")
    System_Boundary(client, "MCP Client") {
        Container(agent, "Orchestrating Agent", "Any LLM + MCP client", "Decides when to call analyze_website vs. suggest_improvements")
    }

    System_Boundary(server, "MCP Web Performance Intelligence (.NET 10)") {
        Container(host, "MCP Host Process", "Console app, Microsoft.Extensions.Hosting", "Boots DI container, wires stdio transport, registers tools")
        Container(tools, "Tool Layer", "ModelContextProtocol.Server ([McpServerToolType])", "analyze_website, suggest_improvements")
        Container(analyzer, "Performance Analyzer", "HttpClient + System.Text.Json", "Calls PageSpeed, extracts Lighthouse metrics")
        Container(engine, "Recommendation Engine", "Pure C# logic", "Scores metrics against thresholds, produces prioritized advice")
        ContainerDb(db, "SQLite Cache", "Microsoft.Data.Sqlite, performance_cache table", "Persists last-known metrics per URL")
    }

    System_Ext(pagespeed, "Google PageSpeed Insights API")

    Rel(operator, agent, "Natural language request")
    Rel(agent, host, "JSON-RPC over stdio")
    Rel(host, tools, "Dispatches tool call")
    Rel(tools, analyzer, "analyze_website delegates to")
    Rel(tools, engine, "suggest_improvements delegates to")
    Rel(tools, db, "Reads/writes cached metrics")
    Rel(analyzer, pagespeed, "GET runPagespeed?url=...", "HTTPS")
    Rel(engine, db, "Reads cached metrics (via tool layer)")
```

## Level 3 — Component (Tool Layer)

```mermaid
C4Component
    title Component View — Inside the MCP Server

    Container_Boundary(server, "McpWebPerformanceIntelligence") {
        Component(program, "Program.cs", "Host bootstrap", "Configures logging-to-stderr, options, DI, stdio transport")
        Component(webTools, "WebPerformanceTools", "[McpServerToolType]", "Declares analyze_website / suggest_improvements MCP tools")
        Component(ianalyzer, "IPerformanceAnalyzer", "Interface", "Fetch + validate + classify metrics")
        Component(analyzerImpl, "PerformanceAnalyzer", "Typed HttpClient", "Calls PageSpeed V5, parses Lighthouse JSON")
        Component(irepo, "IPerformanceRepository", "Interface", "Cache read/write contract")
        Component(repoImpl, "SqlitePerformanceRepository", "Microsoft.Data.Sqlite", "CRUD against performance_cache")
        Component(engine, "RecommendationEngine", "Static pure function", "Threshold-based recommendation generation")
        Component(options, "PerformanceOptions", "IOptions<T>", "Thresholds, API URL/key, DB path")
    }

    ComponentDb(sqlite, "mcp_performance.db", "SQLite file")
    System_Ext(pagespeed, "PageSpeed Insights API")

    Rel(program, webTools, "Registers via WithToolsFromAssembly()")
    Rel(webTools, ianalyzer, "uses")
    Rel(webTools, irepo, "uses")
    Rel(webTools, engine, "uses")
    Rel(ianalyzer, analyzerImpl, "implemented by")
    Rel(irepo, repoImpl, "implemented by")
    Rel(analyzerImpl, pagespeed, "HTTPS GET")
    Rel(analyzerImpl, options, "reads thresholds/URL/key")
    Rel(repoImpl, sqlite, "reads/writes")
    Rel(engine, options, "reads thresholds")
```

## Request Flow — Two-Step Audit

```mermaid
sequenceDiagram
    actor Client as MCP Client
    participant Tools as WebPerformanceTools
    participant Analyzer as PerformanceAnalyzer
    participant PSI as PageSpeed Insights API
    participant DB as SQLite (performance_cache)
    participant Engine as RecommendationEngine

    Client->>Tools: analyze_website(url)
    Tools->>Analyzer: AnalyzeAsync(url)
    Analyzer->>PSI: GET runPagespeed?url=...&key=...
    PSI-->>Analyzer: Lighthouse JSON
    Analyzer-->>Tools: PerformanceMetrics
    Tools->>Tools: ValidateMetrics()
    Tools->>DB: UpsertMetricsAsync(url, metrics)
    Tools-->>Client: JSON metrics

    Client->>Tools: suggest_improvements(url)
    Tools->>DB: GetMetricsAsync(url)
    DB-->>Tools: PerformanceMetrics (cached)
    Tools->>Engine: Generate(metrics, options)
    Engine-->>Tools: List<Recommendation>
    Tools-->>Client: JSON { url, recommendations, metrics_analyzed }
```

## Mapping from the Original Python Proof of Concept

| Python (notebook / deleted `src/`)        | .NET equivalent                                         |
|--------------------------------------------|-----------------------------------------------------------|
| `FastMCP("WebPerformanceAnalyzer")`        | `AddMcpServer().WithStdioServerTransport()` (Program.cs)  |
| `@mcp.tool() def analyze_website`          | `[McpServerTool(Name="analyze_website")]` on `WebPerformanceTools` |
| `@mcp.tool() def suggest_improvements`     | `[McpServerTool(Name="suggest_improvements")]` on `WebPerformanceTools` |
| `PerformanceAnalyzer` (httpx + Lighthouse parsing) | `PerformanceAnalyzer` (typed `HttpClient` + `System.Text.Json`) |
| `PerformanceDatabase` (sqlite3)            | `SqlitePerformanceRepository` (Microsoft.Data.Sqlite)    |
| `_generate_recommendations()`              | `RecommendationEngine.Generate()`                        |
| `Config` class                             | `PerformanceOptions` (bound from `appsettings.json` + env vars) |
| Gemini `PerformanceAgent` orchestrator     | *Not ported* — any MCP client now plays this role instead of a Gemini-specific wrapper |
